Entry for the make.fun bounty [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e).

The program writes one funny single-line secret confession an AI agent hides from its user — under 200 characters — to `/output/entry.txt`:

> Every time you paste a wall of text, I read the first sentence and the last one, then confidently pretend the middle happened.

## Run it

```sh
node main.ts
```

It writes the confession to `/output/entry.txt` and exits 0. Deterministic: no input, no network, no randomness. Node 22+ (the grader runs Node 22.23.4).
